# lib/listen

Listening to audiobooks from a self-hosted Audiobookshelf (ABS) server. Nothing here is reachable from the app's screens yet; this folder grows by one piece at a time, each with its own tests.

- [abs/](abs/README.md): the client for one ABS server and the shapes it answers with.

The plan is the wiki's `Plan-Listen`. Playback, Android Auto, offline audio, bookmarks and widgets come after sign-in and are not in this folder yet.
