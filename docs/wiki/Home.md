# Tippani for Android

A native Android app for keeping quotes that works on its own, with no server, and can pair with a [Tippani](https://github.com/aaronified/tippani)
server so the two stay in step. Source: [aaronified/tippani-app](https://github.com/aaronified/tippani-app). Licence: GPL-3.0.

These pages are the repository's `docs/wiki/`, mirrored to this wiki by a workflow on every push to `main`. **Edit them in the repository:** an edit
made in the wiki's web editor is overwritten by the next sync.

- [Plan](Plan.md): what the app will do, what it reuses, and what is still undecided.
- [Decisions](ADR-Index.md): every decision, in the order it was made, with the reason.
- [Developing](Developing.md): how to build and test it, and how the base the screens stand on is laid out.
- [Releasing](Releasing.md): how a release is cut, and the secrets and keys it needs.
